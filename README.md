# Посудомойка

Общая кухонная панель для семьи: выбрать человека → отметить загрузку или разгрузку. FastAPI, Jinja2 и SQLite; без внешних шрифтов, CDN и сборки фронтенда. Погодный виджет использует Open-Meteo.

## Запуск

Требуется Python 3.10 или новее.

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```

На компьютере откройте `http://localhost:8000`. Папка `data` и база создаются при первом запуске. Запуск возможен из другой директории через `uvicorn --app-dir /путь/к/dishwasher-status server:app --host 0.0.0.0 --port 8000`.

Существующая таблица `events` и все старые записи сохраняются. Дополнительная таблица `submissions` хранит идентификаторы отправки, чтобы повторные запросы не создавали дубли. Отменённая отправка тоже не может появиться повторно.

## Планшет на кухне

1. Подключите планшет к той же домашней Wi-Fi сети, что и компьютер с сервером.
2. Узнайте локальный IP компьютера в настройках сети. На macOS для Wi-Fi обычно подходит `ipconfig getifaddr en0`.
3. Откройте на планшете `http://IP-КОМПЬЮТЕРА:8000` (например, `http://192.168.1.10:8000`). Разрешите Python входящие соединения в локальной сети, если macOS спросит. Компьютер с сервером должен быть включён; для стабильного адреса можно закрепить его IP в настройках роутера.
4. Добавьте страницу на главный экран через меню браузера: в Safari — «Поделиться» → «На экран Домой», в Chrome — «Добавить на главный экран» (название зависит от версии). Также есть кнопка разворота на весь экран в шапке.
5. Для постоянной панели настройте время автоблокировки планшета. Если браузер поддерживает Screen Wake Lock и сайт открыт в безопасном контексте (HTTPS или localhost), полноэкранный режим запрашивает удержание экрана. На обычном локальном HTTP используйте настройки планшета.

Интерфейс рассчитан на альбомную и портретную ориентацию. На общем устройстве человек выбирается для каждой отметки; после 45 секунд бездействия выбор сбрасывается. Светлая/тёмная тема запоминается на устройстве. История автоматически проверяется каждые 30 секунд и после возвращения на вкладку; экран обновляется, когда выбор человека не активен.

Статус показывает только последнюю ручную отметку. «Посуда внутри» не означает, что мойка завершена. Последнюю отметку можно отменить в течение двух минут кнопкой в подтверждении. Случайный двойной тап или повтор сетевого запроса с тем же идентификатором не дублирует запись. При потере связи приложение не показывает ложное подтверждение; незавершённую отправку можно повторить с тем же идентификатором. Отложенной отправки офлайн нет: сервер должен быть доступен для сохранения.

Приложение предназначено для доверенной домашней сети: авторизации нет. Формы работают и без JavaScript; автоматическое обновление, проверка связи и смена темы требуют JavaScript.

## Погода

Рядом с датой и временем отображается погода в Санкт-Петербурге: текущая температура по модели, прогноз минимума/максимума на сегодня и максимальная вероятность осадков за день. Значок показывает текущие условия; их описание доступно в подсказке и скринридере. Источник — [Open-Meteo](https://open-meteo.com/).

Сервер запрашивает фиксированные координаты центра города через HTTPS, без API-ключа. Геолокация планшета не требуется. Данные кэшируются в памяти на 15 минут; каждый браузер обращается только к своему серверу через `/api/weather`. Необходим доступ сервера к `api.open-meteo.com`.

Погода загружается отдельно и не задерживает отметки. При сбое данные за текущий день можно показывать не дольше двух часов с явным временем обновления; после этого отображается «Прогноз недоступен». Повторная попытка — через минуту. Вчерашний прогноз не используется как сегодняшний. После перезапуска сервера кэш наполняется заново.

## Хранение и время

По умолчанию база находится в `data/dishwasher.db` рядом с `server.py`. Для резервного копирования остановите сервер и скопируйте этот файл. Часовой пояс статистики — `Europe/Moscow`, хранение времени событий — UTC, как и в предыдущей версии.

Переменные окружения:

- `DATABASE_URL`: другой путь SQLite, например `sqlite:////absolute/path/dishwasher.db`.
- `DISHWASHER_TIMEZONE`: часовой пояс IANA, например `Europe/Moscow`.

Фильтры «7 / 30 / 365 дней» включают сегодняшний день и предыдущие календарные дни в выбранном часовом поясе. Счётчики и семейный вклад используют один период. При выборе «Всё время» счётчики включают всю историю, а календарь показывает последний год. Серия дней не обрывается до конца сегодняшнего дня, если вчера уже была отметка.

## Docker

```sh
docker build -t dishwasher-status .
docker run --rm -p 8000:8000 -v "$(pwd)/data:/app/data" dishwasher-status
```

Папка `data` на хосте хранит историю между пересозданиями контейнера.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Тесты создают отдельную временную SQLite-базу и не изменяют домашнюю историю.
